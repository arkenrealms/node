# arken/packages/node/legacy/data/generated

Generated legacy content catalogs (JSON).

## Contents
World/gameplay metadata used by legacy loaders, including:
- areas/acts/eras/NPCs
- items and item taxonomies
- skills and skill taxonomies
- character and map/world dictionaries

## Handling guidelines
Treat files as generated artifacts:
- avoid manual edits unless regeneration is impossible,
- keep schema expectations documented in parent analysis,
- prefer integrity checks/tests for high-impact files (`items`, `skills`, `areas`).
